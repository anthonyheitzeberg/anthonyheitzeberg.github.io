# Anthony Heitzeberg — Portfolio

This is a minimal, responsive single-page portfolio for Anthony Heitzeberg. It includes:

- index.html — main page
- styles.css — styling
- script.js — small interactions

How to use
1. Clone your repository locally (or create the repository first on GitHub and then clone).
   git clone https://github.com/anthonyheitzeberg/anthonyheitzeberg.github.io.git
   cd anthonyheitzeberg.github.io

2. Create a branch, add files, commit, and push:
   git checkout -b portfolio-site
   # copy the files (index.html, styles.css, script.js, README.md) into the repo root
   git add .
   git commit -m "Add initial portfolio site for Anthony Heitzeberg"
   git push -u origin portfolio-site

3. Open a Pull Request on GitHub and merge to main (or push directly to main). For a GitHub Pages user site:
   - If you are using the repository `anthonyheitzeberg.github.io`, GitHub Pages will serve the site from the default branch (usually `main`).
   - If you want the site live at https://anthonyheitzeberg.github.io, merge to `main` (or push the files directly to `main`).

Customization
- Replace text and links in index.html (email, social links, project links).
- Add project screenshots: create an /assets or /images folder and reference them from the project cards.
- To use a custom domain, add a `CNAME` file with your domain in the repo root and configure DNS.

Notes
- This site is intentionally small and framework-free so it is easy to maintain.
- If you'd like, I can:
  - generate a ready-to-commit patch and push it into the repository for you (if you enable uploads / allow me to push),
  - or expand the site with a blog, contact form, or a CMS integration.

Enjoy!
